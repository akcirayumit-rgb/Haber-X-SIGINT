▸ SDR++ ile Bağlantı Kurulum

HamItUp + SDR Cihazı → SDR++ → Bu Uygulama

Adım 1 — SDR++ Ses Çıkışı

SDR++ > Audio > Output Device'ı "VB-Cable" veya sistem hoparlörüne ayarla.

Adım 2 — CW Modu

SDR++'da demodülasyon modunu CW (USB/LSB) olarak seç. HamItUp ile HF bandı için 0–30 MHz izlenebilir.

Adım 3 — Frekans Ayarı

SDR++'dan çıkan ses CW tonu genellikle 500–900 Hz aralığında. Sol panelden frekans kaydırıcısını ayarla.

Adım 3b — SDR++ Network Sink (VB-Cable Alternatifi)

SDR++ > Module Manager > Network Sink ekle. Protokol: WebSocket, port: 4444, format: Float Mono. Sol panelde "SDR++ / Hamlib" bölümünden URL gir ve ▶ bas. VB-Cable gerekmez.

Adım 3c — Rigctl / Hamlib Frekans Senkronizasyonu

SDR++ > Module Manager > Rigctl Server ekle. Port: 4532. Sol panelden "Rigctl Sunucu" alanına localhost:4532 yaz ve bağlan. SDR++'da frekans değiştirince bu uygulamada otomatik güncellenir.

HamItUp +125 MHz Offset

Sol panelde "HamItUp +125 MHz Offset" anahtarını aç. Gösterilen frekanslar otomatik olarak 125 MHz düşürülerek gerçek RF frekansı gösterilir. Örnek: SDR++ 131.550 MHz gösteriyorsa gerçek frekans 6.550 MHz (HF bandı).

AIS Gemi Takibi

brew install ais-catcher · Çalıştır: ais-catcher -H 8090 · AIS sekmesinden http://localhost:8090/vessels bağlan. Frekans: 161.975 / 162.025 MHz FM.

Haber-X Entegrasyonu

Bu uygulamada çözülen metin KOPYALA butonu ile Haber-X'e yapıştırılabilir. "Haber-X Entegrasyonu" bölümünden tüm SIGINT verisi JSON olarak gönderilebilir.
